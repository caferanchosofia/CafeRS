# Café Rancho Sofía & La Crêpe — Carta digital

Carta digital con pedidos por WhatsApp.

## Cómo correrlo

```bash
npm install
npm run dev
```

Abre la URL que muestre Vite (por defecto `http://localhost:5173`).

## Scripts

- `npm run dev` — desarrollo
- `npm run build` — genera un HTML único en `dist/`
- `npm run preview` — previsualiza el build

## WhatsApp

Los pedidos salen al **+504 9975-3442**.
Para cambiarlo, edita `DEFAULT_WHATSAPP` en `src/data/menu.ts`.
